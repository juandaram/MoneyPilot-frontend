1. Objetivo del Sprint

El propósito del Sprint 1 fue establecer la base técnica y conceptual del proyecto MoneyPilot, incluyendo la configuración inicial del entorno de desarrollo, la definición de la arquitectura del sistema, y la implementación de prototipos funcionales para los módulos principales.

El objetivo adicional fue desarrollar un modelo preliminar de cálculo de salud financiera y definir los fundamentos visuales y de interacción de la aplicación, asegurando que la estructura resultante sea escalable para futuras integraciones, incluyendo módulos de inteligencia artificial.

2. Entregables Principales

2.1 Backend

Repositorio: money-pilot-backend
Tecnologías: Python, SQL, FastAPI (o framework equivalente), Pytest

Avances:

  • Configuración del entorno de desarrollo y del servidor backend.
  • Definición inicial del esquema relacional de la base de datos.
  • Implementación de endpoints básicos para autenticación y gestión de usuarios.
  • Ejecución de pruebas unitarias iniciales mediante Pytest.
  • Documentación técnica y preparación de endpoints para integración futura con el frontend.

2.2 Frontend

Repositorio: MoneyPilot-frontend
Tecnologías: Next.js, React, Tailwind CSS, JSON

Avances:

  • Creación de la estructura del proyecto en Next.js con componentes modulares en React.
  • Implementación de estilos visuales con Tailwind CSS, priorizando una interfaz limpia y minimalista.
  • Desarrollo de vistas iniciales: inicio de sesión, registro y panel de usuario (dashboard).
  • Despliegue exitoso del frontend en Vercel: money-pilot-frontend.vercel.app.
  • Modelado de los datos mediante archivos JSON de ejemplo, que simulan la información proveniente del backend.
    Aún no se ha realizado la integración directa con la API, pero el sistema está preparado para consumir datos reales cuando el backend esté completamente funcional.

2.3 Diseño UI/UX

Wireframe en Figma: Prototipo MoneyPilot

Avances:

  • Creación del flujo general de navegación del usuario: autenticación, cuestionario y dashboard.
  • Diseño de wireframes de baja y media fidelidad con enfoque en accesibilidad y claridad visual.
  • Definición de una línea estética sobria con elementos que evocan un asistente financiero de carácter confiable y empático.
  • Planificación de mejoras visuales para pruebas de usabilidad en el próximo sprint.

2.4 Módulo de Cálculo Financiero

Script Python: Calculadora de Financial Health

Avances:

  • Desarrollo del algoritmo para evaluar la salud financiera del usuario a partir de variables como ingresos, egresos y deudas.
  • Implementación de estructuras de salida en formato JSON compatibles con la lógica del frontend.
  • Validación con casos de prueba y simulaciones.
  • Este módulo servirá como base para la futura integración de microservicios financieros y modelos predictivos.

4. Retos y Aprendizajes

Retos:

  • Sincronización entre las estructuras de datos del frontend y el backend.
  • Coordinación entre los flujos de diseño y desarrollo.
  • Ajuste de dependencias y librerías en el entorno de Next.js y Python.

Aprendizajes:

  • Dominio de despliegue continuo utilizando Vercel.
  • Implementación de entornos controlados para pruebas unitarias.
  • Fortalecimiento en diseño de interfaces responsivas y escalables.

5. Escalabilidad e Integración de Inteligencia Artificial

Aunque en esta fase no se implementó ningún componente de inteligencia artificial, la arquitectura del sistema fue diseñada para soportar futuras integraciones de modelos de IA.
En fases posteriores, se prevé la incorporación de un asistente financiero conversacional y un motor de recomendaciones personalizadas, basados en aprendizaje automático y análisis predictivo de comportamiento financiero.

6. Plan para el Sprint 2

Objetivos principales:

  • Integrar completamente el backend con el frontend mediante API REST.
  • Implementar persistencia real de datos en la base de datos SQL.
  • Desarrollar el cuestionario de perfil financiero y la visualización dinámica de resultados.
  • Incorporar métricas y reportes automáticos en el dashboard.
  • Avanzar en pruebas de usabilidad y recolección de retroalimentación de usuarios.

7. Conclusión

El Sprint 1 permitió consolidar la base tecnológica y de diseño del proyecto MoneyPilot.
Se logró establecer una arquitectura funcional, un prototipo navegable y un módulo lógico de evaluación financiera.
Aunque la integración total entre backend y frontend aún está pendiente, la estructura general del sistema garantiza escalabilidad, mantenibilidad y potencial de expansión hacia módulos de inteligencia artificial en etapas posteriores.
